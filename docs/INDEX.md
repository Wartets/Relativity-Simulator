# Documentation Index

This directory contains the formal technical documentation for the Relativity-Simulator.

## Core Documents

- [DESCRIPTION.md](DESCRIPTION.md)  
  System-level specification, scientific scope, runtime modes, and validation scenarios.

- [ARCHITECTURE.md](ARCHITECTURE.md)  
  Software architecture, subsystem boundaries, render pipeline, capture subsystem, profiling, constants engine, concurrency model, scheduling, and precision design.

- [TECHNICAL_MANUAL.md](TECHNICAL_MANUAL.md)  
  Implementation-oriented component overview, renderer back ends, metric usage by the ray tracer, interface modules, and internal engineering constraints.

- [MATHEMATICAL_FORMULATION.md](MATHEMATICAL_FORMULATION.md)  
  Governing equations, metric definitions, geodesics, transport equations, and PN terms, together with the ray-tracing, disk, tone mapping, body shading and motion script formulas used by the implementation.

- [FILE_FORMATS.md](FILE_FORMATS.md)  
  YAML scenario schema, FITS/HDF5/VTK structures, ephemeris ingestion conventions, image formats, capture session and telemetry files, motion script files, and persistent configuration files.

- [CLI_REFERENCE.md](CLI_REFERENCE.md)  
  Interactive REPL commands, performance presets, navigation modes, keybindings, menus, and headless exporter options.

- [TREE.md](TREE.md)  
  Repository layout.
